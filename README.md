# Alisha Batool | Portfolio

A modern personal portfolio website built with React, Vite, and Tailwind CSS.

## Live Demo

https://github.com/Alisha-Batool/portfolio

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Features

- Modern dark portfolio design
- Responsive layout
- Animated hero and UI sections
- Contact form with email integration
- Social links for GitHub, LinkedIn, and email

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
